# Foundational Runtime Systems

These are the major runtime systems that do not yet exist and block 2.0 release:

- [ ] Conversation runtime for `talk`
- [ ] Combat, death, and corpse infrastructure
- [ ] Skills/language progression infrastructure
- [ ] Quest giving, quest receipt, and quest completion infrastructure
- [ ] Currency/barter infrastructure sufficient to settle death-debt obligations with the King or Unto
- [ ] Canonical monotonic tick accessor plus staged sequence/session helpers
- [ ] Ritual-local semantic-event helper layer
